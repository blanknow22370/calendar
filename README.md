# Chronicle Forge · 无限分支时间轴

一个无需构建步骤的中文时间轴编辑器原型，面向历史整理、人物小传和架空世界观创作。

## Windows 桌面版

打包后的目录版入口为 `ChronicleForge.exe`。程序无需安装 Node.js；请保留 EXE、`resources`、`locales` 和 DLL 文件在同一目录。首次运行会在程序旁创建 `data`，其中保存浏览器项目数据和窗口状态，备份或迁移时复制整个程序目录即可。

桌面版增加 Windows 原生项目打开/保存对话框，快捷键为 `Ctrl+O` 和 `Ctrl+Shift+S`。开发目录可用 `npm.cmd start` 启动桌面调试，用 `npm.cmd run package:win` 重新生成 `release/ChronicleForge-win32-x64`。

## 运行

推荐在此目录启动静态服务器：

```powershell
npm.cmd run serve:web
```

随后打开 <http://localhost:4173>。也可以直接双击 `index.html`，但浏览器对本地页面的跨域限制可能阻止联网检索。

网页版本是纯静态站点，没有构建步骤。要发布到公网（GitHub Pages、Netlify、Vercel 或自有服务器），见 [DEPLOY.md](DEPLOY.md)。

## 已实现

- 无预设年份边界的平移与锚点缩放，支持公元前与很大的年份
- 多世界线、分歧年份、分支连线和分支颜色
- 任意节点双击插入，人物、事件、时代、设定四类节点
- 密集节点自动分层排布，时代范围以延伸光带表示
- 中文自然语言时间线解析和导入预览
- 通过中文维基百科公开 API 搜索资料，并可把摘要和来源填回节点
- 浏览器本地自动保存、撤销/重做、JSON 导入导出
- 总览、迷你地图和沉浸式演示模式
- 右侧事件卡片库，可检索、定位，并拖入轨道复制节点
- 轨道节点支持横向拖动改年份、纵向拖动换轨，区间节点可拖动手柄调整结束年份
- 文件拖入时间线自动建卡（小于 1 MB 的文件可内嵌保存，大文件保存元数据）
- 轨线支持折叠、拖动排序、重命名和颜色编辑
- 轨线可从编辑窗口安全删除，并级联删除所属事件卡、解除子轨线父级和清理卡片引用
- 聚焦搜索会同步高亮轨道节点并过滤卡片库，按 Enter 可循环定位结果
- 节点可自定义标记颜色和符号
- 统一时间刻度支持年、月、日、时、分、秒输入，并可缩放到秒级网格
- 内置公历闰年换算；可导入、切换和删除自定义历法，切换历法不会改变事件实际时间点
- 真正的多级“面线—子面线—轨线”层级，支持父级折叠、排序、轨线归属和拖动迁移
- 面线时间轴头部提供 `↕` 高度控制，拖动可调整该面线及继承它的下级轨线纵向密度，并支持撤销
- 每条轨线拥有贯穿时间轴的独立横线，与纵向时间刻度形成十字网格；面线背景、边界、面线标签和轨线标签分别编码
- 跨来源素材库并行检索中文维基、Wikidata 与 Open Library，结果可点击或拖入时间线
- 素材库输入关键字即自动检索；来源可开关、拖动排序，结果严格按用户定义顺序分组并持久保存
- 自建事件、外部素材和文件节点使用不同的卡片标签与视觉编码；文件节点右栏显示文件名、类型、大小、修改时间和保存方式
- 详细内容使用独立全屏工作区；右栏改为可折叠功能集合，节点右键可打开详情、复制、搜索素材或删除
- 同一轨线中结束时间与下一节点开始时间相同的事件默认接续为同一行；可对节点选择“强制分行”，明确表示时间相接但逻辑不连续
- 顶部支持年/月/日粒度切换；年、月、日连续关系分级匹配，细粒度下继承上级连续链同行且不跳行
- 连续链按总持续时长从长到短置顶，独立事件默认位于下方；纵向拖动可保存自定义行序
- 区间条点击即可定位事件开始端，结束手柄按需显隐且悬停不改变区间条高度
- 节点标题、时间、轨线、类型、内容、来源和外观修改会自动保存，并作为单次编辑进入撤销/重做历史
- 新增“紫樱工作台”主题，使用 `#040316`、`#fbfbfe`、`#8b47b7`、`#ffdbf2`、`#ff3da5` 五色系统

## 快捷操作

- 双击轨道空白处：创建新事件卡片
- 拖动轨道卡片：改变开始年份；上下拖动可移动到其他轨线
- 拖动区间卡片顶部末端手柄：调整结束年份
- 区间端点超出当前视窗时会隐藏伪手柄并在边缘显示 `‹/›` 延续提示；缩放或平移到真实端点后手柄才出现
- 从右侧卡片库拖入轨道：在目标年份和轨线创建副本
- 从系统拖入文件：在目标位置创建带附件的卡片
- `Ctrl+F`：聚焦时间线搜索；`Enter`：跳到下一条结果
- 左侧 `⠿`：拖动调整轨线顺序；`−/＋`：折叠或展开轨线；`…`：编辑名称与颜色
- 轨线编辑窗口中的“删除时间线”：删除该轨线及全部所属卡片；可用 `Ctrl+Z` 撤销
- 时间输入格式：`年-月-日 时:分:秒`，例如 `2026-07-26 12:34:56`；公元前年份使用负数
- 顶部历法按钮：切换公历或导入自定义历法 JSON
- 左侧“面”：创建面线；面线可嵌套，折叠父面线会隐藏全部下级轨线
- 时间轴右上角面线标签的 `↕`：上下拖动调整面线显示高度；子面线未单独设定时继承父级高度
- “素材库”：输入即聚合搜索三个外部来源；拖动来源行可调整显示顺序，将结果拖到轨道可在目标时间和轨线建卡，“加入中心”落在当前视图中心
- 单击节点：在右侧打开折叠式功能集合；点击“打开详细页面”编辑长内容
- 右键节点：打开快捷控制菜单，可进入详情、创建副本、搜索相关素材或删除
- “时间与轨线 → 相接事件显示”：选择自动连贯或强制分行；自动模式会显示实际接续的前序节点
- 顶部“年 / 月 / 日”：切换显示粒度；端点始终使用实际精确时间，连续链只改变关系标签、不改变所在行
- 单击区间条：直接定位到该事件开始端；悬停或选中区间节点后拖动末端手柄可修改精确结束时间
- 在同一轨线内上下拖动节点：调整连续链/独立事件的行序；连续链成员不会被拆行

## 数据格式

项目版本 3 由 `calendars`、`surfaces`、`branches` 和 `events` 组成。项目级 `materialSourceOrder`/`materialSourceEnabled` 保存素材来源偏好；事件级 `origin` 区分 `manual`、`material`、`file`，`continuityMode` 使用 `auto` 或 `separate` 控制与同轨前序节点的接续显示。`startTime`/`endTime` 是从公历 0 年 1 月 1 日起算的统一日刻度，小数部分精确到秒；不依赖 JavaScript `Date` 的年份范围：

```json
{
  "version": 3,
  "activeCalendarId": "gregorian",
  "materialSourceOrder": ["wikipedia", "wikidata", "openlibrary"],
  "calendars": [{ "id": "gregorian", "name": "公历", "type": "gregorian" }],
  "surfaces": [{ "id": "surface-1", "name": "主叙事面", "parentId": null }],
  "branches": [{ "id": "branch-1", "surfaceId": "surface-1", "name": "现实史线", "forkYear": 1206 }],
  "events": [{ "id": "evt-1", "branchId": "branch-1", "origin": "manual", "startTime": 499400, "startYear": 1368, "title": "明朝建立" }]
}
```

`startYear`/`endYear` 作为旧版兼容坐标继续导出。版本 3 会自动迁移 v1/v2 项目，为旧事件生成统一时间刻度、默认面线和公历配置。建议升级前先导出 JSON 备份。

自定义历法示例：

```json
{
  "name": "星历",
  "months": [30, 30, 30, 30, 30, 30, 30, 30, 30, 30, 30, 30],
  "secondsPerDay": 86400,
  "epochDay": 0
}
```

当前自定义历法支持固定月份结构、日长度和纪元偏移；复杂的周期闰月规则尚未加入规则语言。详细变更见 [CHANGELOG.md](CHANGELOG.md)。

浏览器版本的“理论无限”指时间坐标不依赖固定宽度 DOM；视窗只渲染当前年份范围附近的节点。若要承载数十万节点，可在现有数据模型上继续加入 IndexedDB 和空间索引。
